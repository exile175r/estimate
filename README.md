# 견적 작업실

## 2026-10-05 추가 기능

- 단가 쉼표 입력, 전체/개별 할인 택일, 개당 금액 할인, VAT 포함 체크박스 및 공급가액·세액·최종 합계.
- 업체·수신처·발행자·납기·결제 조건·유효기간, 수정 가능한 발행일, 발행자 기본값 재사용.
- 브라우저 자동 임시 저장·새로고침 복구. Google 토큰은 보관하지 않으며 Drive 작업에는 재연결이 필요합니다.
- Google Drive 루트 아래 업체별 폴더에 JSON·PDF 저장, 재저장 및 업체 변경 시 이동. JSON과 PDF 저장 상태를 구분합니다.
- 견적 상태 드롭다운, 프로젝트 업무·완료 체크·진행률, 후속 연락 및 업무 마감일 캘린더.
- 업무·일정·발행자 기본값은 **일정·업무 → 업무·설정 Drive 저장**으로 영구 저장합니다. 견적 저장과 별도입니다.
- **PDF 내려받기**는 Drive 보관과 동일한 한글 이미지 PDF를 생성합니다. 텍스트 선택이 필요한 PDF는 **인쇄 / PDF 미리보기**를 사용합니다.

현재 구현·검증과 실제 계정 검증의 구분은 [추가 기능 검증 기록](FEATURE_QA.md)을 참고하세요. 아래 초기 구현 기록의 '인증 보류·메모리 전용·임시 계산' 설명은 당시 상태입니다.

SPEC.md에 따른 HTML / CSS / JavaScript 웹앱입니다. 앱 실행에는 프레임워크·DB·외부 패키지를 사용하지 않습니다. 브라우저/PDF 검증 도구는 개발 의존성으로만 사용합니다.

## 실행

### Google 로그인 설정을 포함한 배포

`src/config.js`는 Git에 포함하지 않는 빌드 생성 파일입니다. 저장소 소스를 그대로 GitHub Pages에 배포하면 이 파일이 404가 되어 로그인 창이 열리지 않습니다. 설정된 환경에서 `npm run build`를 실행하고 **생성된 `dist/` 전체를 배포**해야 합니다. `.env`나 OAuth 비밀키·토큰을 배포하거나 Git에 추가하지 마세요. 빌드는 허용된 공개 런타임 설정만 생성합니다.

로그인에는 OAuth 클라이언트 ID와 Google 로그인 스크립트가 필요합니다. API 키·프로젝트 ID는 로그인 이후 폴더 선택에 사용하며, 해당 설정 오류가 로그인 창까지 막지 않도록 분리했습니다.

```sh
npm start
```

브라우저에서 `http://localhost:8000`을 엽니다. ES 모듈을 사용하므로 HTML을 직접 파일로 열지 않습니다. Codespaces에서는 Ports 탭에서 8000 포트를 엽니다.

```sh
npm test
```

Node.js 22.13 이상(검증 환경: 24.21.0)에서 실행합니다. Python은 필요하지 않습니다.

화면·PDF 테스트:

```sh
npm ci
npx playwright install --with-deps chromium
npm run test:ui
```

한글 PDF 시각 검증에는 OS에 한글 글꼴(예: Noto Sans KR)이 있어야 합니다. 이 Codespaces에서 준비한 임시 브라우저·글꼴을 이용하려면 다음 명령을 사용합니다. 임시 경로는 환경 재생성 시 사라질 수 있습니다.

```sh
FONTCONFIG_FILE=/tmp/estimate-fonts.conf PLAYWRIGHT_BROWSERS_PATH=/tmp/estimate-browsers npm run test:ui
```

실제 검증 결과와 수용 기준 대조표는 [QA.md](QA.md)에, 화면 캡처와 PDF는 [artifacts/qa](artifacts/qa)에 있습니다. 테스트 데이터는 테스트 브라우저 메모리에서만 만들며 실제 Drive에 저장하지 않습니다.

## 사용

1. 단가표 관리에서 루트 그룹, 하위 그룹, 항목을 만듭니다.
2. 대상을 선택해 이름·단가·단위·설명을 편집합니다. 트리 이름 변경은 Enter 또는 포커스 이동으로 반영하고 Escape로 취소합니다.
3. 트리 행에 드롭하면 대상 앞에 정렬됩니다. 폴더의 ‘안으로’에 드롭하면 그 폴더로 이동합니다. 하단 루트 영역에는 그룹만 이동할 수 있습니다.
4. 견적 작성 화면에서 항목을 선택하고 미리보기 안에서 내용을 수정합니다. 중복 선택은 매번 추가 방식을 묻습니다.
5. 인쇄 / PDF 미리보기에서 브라우저의 PDF 저장을 사용할 수 있습니다. 이는 잠정 출력 방식이며 Drive 저장이 아닙니다.

작성 중인 견적·단가표·업무는 이 브라우저에 자동 임시 저장됩니다. 영구 보관에는 Google 연결과 Drive 저장이 필요합니다. Google 토큰은 저장하지 않으므로 새로고침 후 다시 연결해야 합니다. 브라우저 데이터를 삭제하면 복구용 초안도 없어집니다. 로컬 임시 저장이나 모의 테스트 결과를 Drive 저장 성공으로 취급하지 않습니다.

## 파일 구조

- `index.html`: 작성·관리자·저장 목록 화면과 중복 선택 대화상자
- `styles.css`: 반응형 화면과 임시 인쇄 스타일
- `src/model.js`: 트리·이동·복제·견적 스냅샷
- `src/calculation.js`: 전체/개별 할인, VAT, 합계 및 기존 계산 보존
- `src/storage.js`: Drive 업체 폴더, 견적·PDF·단가표·업무 저장과 재조회 검증
- `src/recovery.js`: 브라우저 복구용 저장
- `src/workflow.js`: 프로젝트·업무·일정 데이터
- `src/pdf.js`: 한글 이미지 PDF 생성
- `src/app.js`: 화면 이벤트와 렌더링
- `tests/model.test.js`: 핵심 규칙 및 실패 처리 검증
- `tests/browser/`: 실제 Chromium 조작·반응형·PDF 검증
- `scripts/serve.js`: Node.js 개발용 정적 서버
- `playwright.config.js`: 브라우저 검증 설정
- `QA.md`: 검증 결과와 한계
- `TODO.md`: 구현 범위와 미결정 사항

신규 견적은 VAT 10%와 원 단위 반올림을 적용합니다. 기존 견적은 기존 계산을 유지하며 사용자가 명시적으로 새 계산을 선택할 수 있습니다. 자세한 규칙은 FEATURE_PLAN.md를 참고하세요.
